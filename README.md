# Kit gratuito: series participativas con IA

Método, prompts y plantillas para crear una serie donde los comentarios, los seguidores o los me gusta producen cambios visibles en un mundo 3D.

## Descargar

[Descargar el kit completo (ZIP)](./KIT_METODO_1_IA.zip?raw=true)

[Descargar la guía práctica (PDF)](./METODO_1_SERIES_PARTICIPATIVAS.pdf?raw=true)

La descarga es gratuita. No necesitas una cuenta de GitHub para descargar archivos de este repositorio público.

## Empezar

1. Descarga y extrae el ZIP.
2. Abre la carpeta `kit_para_ia` en tu agente con acceso a los archivos.
3. Lee `LEEME_KIT.md` y completa `PROMPT_INICIO.txt` con tu temática, meta, episodios y regla de participación.
4. Pide la preproducción y revisa las reglas, las fichas y el storyboard.
5. Produce una prueba pequeña antes de toda la biblioteca. El agente ejecuta las herramientas disponibles y conserva archivos editables y capturas de control.

El ejemplo de colonia lunar incluye un brief, un storyboard y un recorrido guiado. Puedes cambiarlo por un estadio, una escuela de magia, una ciudad u otra temática.

## Qué incluye

- Guía práctica de 15 páginas con requisitos, método, solución de problemas y 13 archivos esenciales impresos.
- Prompt inicial e instrucciones para el agente.
- Plantillas de brief, recursos, storyboard, timeline, participación y continuidad.
- Ejemplo guiado de una colonia lunar.
- Texto portable para que la IA pueda leer el método.
- Utilidad para medir audios y videos con FFprobe.

El PDF también contiene el kit como archivo adjunto. Si tu visor no permite extraerlo, utiliza el ZIP.

## Herramientas

El flujo utiliza ChatGPT/Codex o Claude Code, Blender, Unity y edición de video. La generación de clips con OmniFlash o Flow es opcional. La voz se puede entregar como audio o generar con un servicio como ElevenLabs.

El agente necesita acceso real a los programas. El kit no incluye modelos terminados, licencias de servicios ni resultados garantizados de seguidores. Los campos `null` son datos pendientes y los ejemplos simulados están identificados.

Antes de publicar tu serie, revisa imagen y sonido y anuncia reglas de participación que puedas cumplir.
